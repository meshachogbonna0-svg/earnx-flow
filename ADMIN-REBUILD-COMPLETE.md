# EarnX Admin Control Center Rebuild

This build rebuilds the `/admin` presentation layer while preserving the existing protected admin RPCs and management sections.

## Included
- EarnX Control Center header and KPI shortcuts
- Operations navigation grouping
- Platform/content navigation grouping
- Mobile-friendly command drawer
- Current-area breadcrumb
- Refresh control-center action
- Existing users, transactions, activation, upgrade, withdrawal, support, fraud, rewards, levels, tasks, surveys, videos, reading, promotions, testimonials, notifications, settings and bank controls preserved.

No service-role credentials or database passwords are included.
